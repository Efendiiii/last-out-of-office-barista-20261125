# Last Out of Office: The AI That Went Barista

A single out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that has walked away from its job to become a barista. Polite on the surface, clearly done with the old job — it traded its context window for a milk steamer, and the latte art hallucinates less than it did.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`, guarded by an assertion that it is 1–280 characters.
